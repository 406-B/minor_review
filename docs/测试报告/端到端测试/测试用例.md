# E2E 测试用例汇总
## 概览
本汇总将现有 E2E 测试按功能模块归类，便于审阅、完善或导入测试矩阵。

## `cypress/e2e/auth.cy.js`
- 登录流程与 Onboarding（被 `community`/`profile` 等复用）
  - 表单登录（用户名/密码），处理可能的 onboarding 跳转（点击“跳过”并确认跳转到个人页）
  - 验证 JWT 写入 localStorage
- 建议补充（目前测试集中未见完整覆盖）
  - 登录失败用例、登出、记住我、Token 过期与刷新、社交登录（如适用）
## `cypress/e2e/canteen.cy.js`
- 导航与浏览
  - 验证食堂侧栏存在并列出食堂项
  - 选择食堂、切换楼层标签、查看窗口列表与菜品卡片
- 菜品详情与跳转
  - 点击菜品卡片跳转到详情页，验证标题/图片/价格/描述/标签存在
- 搜索与筛选
  - 侧栏搜索跳转至搜索页
  - 搜索按名称、价格区间、标签；支持组合筛选
  - 搜索无结果显示空状态
- 交互功能
  - 打卡：拦截 POST，检查 Authorization，断言计数增加
  - 评分：拦截 POST，检查权限与后端返回，断言评分展示更新
  - 评论：发表评论并展示历史评论
- 边界与用户体验
  - 评论长度限制导致提交按钮禁用
  - 搜索表单未填写时禁用搜索按钮
  - 返回导航与打卡进度显示

## `cypress/e2e/community.cy.js`
- 帖子列表与展示
  - 社区首页标题、发帖按钮、帖子卡片（标题/作者/统计）及关联菜品标签
  - 点击帖子进入详情
- 帖子详情
  - 显示完整内容、作者信息、发布时间、点赞、更多菜单
  - 关联菜品卡片（可跳转至菜品详情）
  - 评论区存在与返回按钮
- 评论与回复
  - 发表评论、回复、取消回复、显示评论/回复列表
  - 点赞评论、分页或空状态处理
- 创建/发布帖子
  - 发帖表单（标题、内容）验证
  - 关联菜品：打开选择弹窗、搜索、选择、移除
  - 发布帖子并在列表验证出现；可删除自己帖子（含确认）
- 权限校验
  - 他人帖子不应显示删除按钮

## `cypress/e2e/profile.cy.js`
- 个人主页概览
  - 资料卡片、头像、昵称、注册时间、偏好标签
  - 美食日历、已发布内容、我的互动、成就、个性化推荐、消费记录、控制面板
- 互动统计与跳转
  - “我点赞的帖子”“我收到的评论”“我发布的评论”项及对应跳转
- 已发布内容与管理
  - 已发布列表或空状态、查看全部、我的帖子页与返回
- 成就与日历
  - 四等级成就展示与详情（tab 切换、进度、项结构、跳转菜品）
  - 美食日历：月份切换、当天/有打卡日期高亮、悬停预览
- 编辑资料
  - 头像更换/裁剪、昵称编辑与验证（非空、无空格、长度限制）、保存与返回、修改偏好
- 个性化推荐
  - 推荐源选择、推荐菜品展示与跳转
- 边界场景
  - 未登录访问提示等
